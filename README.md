# Proyecto Traspatio
Aplicación móvil para la construcción y mantenimiento de **Jardines Polinizadores en Traspatio**.

## Propósito
Desarrollar una aplicación que permita informar, guiar y organizar la creación de espacios naturales en casa, facilitando el catálogo de plantas y cuidados básicos.

## Tecnologías
- HTML5
- CSS3
- GitHub Pages (Alojamiento)
